# 校园新闻及通知发布系统（课程设计）

技术栈：Python Flask + 原生 HTML/CSS（Jinja2 模板）+ SQLite

## 运行方式

```bash
pip install -r requirements.txt
python app.py
```

浏览器访问 http://127.0.0.1:5000

首次运行自动创建 `campus.db` 并写入示例数据。

## 功能说明

- **用户端（前台）**：顶部菜单栏布局，首页 / 校园新闻 / 通知公告浏览，支持分类筛选、关键词搜索、分页、浏览量统计；右上角"用户名下拉菜单（个人中心）+ 退出按钮"。
- **管理端（后台，`/admin/`）**：左侧菜单栏 + 右侧内容区布局，包含：
  - 系统首页：数据统计（新闻数、通知数、用户数、总浏览量）
  - 新闻管理：发布 / 编辑 / 删除、置顶、草稿状态
  - 通知管理：发布 / 编辑 / 删除、重要标记、草稿状态
  - 分类管理：新闻分类的增删
  - 用户管理：添加用户、重置密码、删除用户
- **个人中心**（前后台通用）：修改姓名、邮箱；校验原密码后修改密码。
- 权限控制：未登录跳转登录页，普通用户访问后台返回 403。

## 目录结构

```
app.py               主程序（前台、认证、个人中心）
routes_admin.py      后台管理路由（Blueprint）
static/css/style.css 全局样式
templates/           Jinja2 模板（user_base / admin_base 两套布局）
campus.db            SQLite 数据库（首次运行自动生成）
```
